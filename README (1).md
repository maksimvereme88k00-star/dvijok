# Движение — Telegram Mini App

Весь клиент — один файл `index.html`. Сборка и Node.js не нужны.

## Как запустить (GitHub Pages + бот)

1. **Репозиторий.** На github.com нажмите New repository, назовите, например, `dvizhenie`, сделайте его Public.
2. **Загрузка.** Add file → Upload files → перетащите `index.html` → Commit changes.
3. **Хостинг.** Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → Save.
   Через 1–2 минуты появится адрес вида `https://ВАШ-НИК.github.io/dvizhenie/`.
4. **Бот.** В Telegram откройте @BotFather → `/newbot` → задайте имя и username.
5. **Mini App.** В @BotFather: `/newapp` → выберите бота → название «Движение», описание → пропустите фото/GIF (или загрузите) → вставьте адрес из шага 3 → придумайте короткое имя.
   Также можно: `/mybots` → ваш бот → Bot Settings → Menu Button → задать тот же URL — тогда в чате с ботом появится кнопка запуска.
6. Откройте бота и нажмите кнопку меню — приложение запустится внутри Telegram.

## Где хранятся данные

- В Telegram — через `Telegram.WebApp.CloudStorage`. Данные привязаны к аккаунту Telegram и доступны на всех устройствах, отдельный сервер и база не нужны. Токен бота в приложении не используется.
- Копия хранится и в `localStorage` (работает офлайн). При открытии берётся более свежая версия.
- Лимит: около 3 МБ данных на пользователя.

## Что сделано

Экраны «Сегодня», «Привычки», «Фокус», «Статистика», «Ещё» (задачи, цели, заметки, сон, дневник, настройки); серии привычек, таймер по абсолютному времени `endsAt`, 6 тем из handoff и тема «Как в Telegram», акцентный цвет, три шрифта, размеры 16/18/20, плотность, скрытие экранов и блоков, экспорт/импорт JSON `version: 2` с валидацией и подтверждением, BackButton, HapticFeedback, `ready()`/`expand()`.

## Отличия от handoff

- Нет своего backend: вместо REST API и БД используется CloudStorage. При одновременных правках на двух устройствах побеждает более поздняя запись целиком.
- Шрифты подключаются с Google Fonts, а не из локальной папки `fonts/`.
- Пользовательские обои (картинка) не перенесены — не помещаются в лимиты CloudStorage. Есть декоративные фоны.
- Серверная проверка `initData` (HMAC) не нужна, пока нет своего сервера. Если позже понадобится backend, её нужно будет добавить.
- Экспорт: кроме скачивания файла есть кнопка «Копировать» — в WebView Telegram скачивание работает не везде.
